# MakeItMine Frontend Demo

A responsive, multi-page personalized-gifts storefront built with HTML, CSS and vanilla JavaScript.

## Run locally

1. Extract the ZIP.
2. Open the `MakeItMine-Frontend` folder in VS Code.
3. Recommended: use the Live Server extension and open `index.html`. You can also open `index.html` directly in a modern browser.

## Pages included

- Home, Shop, Categories, Product Detail
- Customize T-shirt preview
- Cart, Checkout, Demo Payment, Order Success, Order Tracking
- Wishlist, Login, Signup, Profile
- About and Contact

## Notes

- Product data lives in `js/data.js`.
- Shared styles live in `css/style.css`.
- Cart, wishlist, demo account and demo orders use browser `localStorage`.
- Authentication and payments are demonstrations only. No real payment is processed and no backend is connected.
- Product and hero photos are loaded from Unsplash URLs, so an internet connection is needed for those images.
- This is a frontend starter project; before production, add a secure backend, real authentication, server-side order storage, payment gateway integration, shipping/tax rules and proper privacy/security handling.
